# Changelog

## 1.0.0 (2026-11-11)

- First stable release.

## 0.1.3 (2026-11-11)

- The language list shows what the content has: untick a language to remove it, tick one to add it.
- "Translate again" option for languages that are already translated.
- When only the source language is left, the content goes back to plain HTML.
- Translations that lose HTML tags or change link targets are retried automatically.
- Blocks with no letters (numbers, symbols) are no longer translated.
- Progress shows the current language and position ("2 of 5").
- Cleaner language names ("Spanish (es)").
- The target languages chosen last time are remembered in the browser.
- Clear error message when the AI service cannot be reached.

## 0.1.0 (2026-11-11)

- First version: translate editor content into several languages with the Moodle AI subsystem.
